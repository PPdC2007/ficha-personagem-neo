# ficha-personagem-neo
Atividade de Tecnogia Web
Por Pedro Pontes da Cunha

Apresenta um personagem fictício original chamado **Neo Aishyne Salleh**.
A primeira página apresenta sua identidade e seu passado.
Ao apertar *Ficha RPG*, entra em outra página que apresenta mais detalhes sobre o personagem, direcionado a jogo de RPG.
